## Review focus

1. **Time zones for carry-over.** A chore due "today" for an assignee in Asia/Jerusalem must not move at UTC midnight, only after local midnight. Test with `preferences.timezone`.
2. **Bulk move of a parent plus its subtasks.** When both are selected, each moves once with a unique new number. A selected subtask whose parent isn't selected becomes top-level in the target.
3. **Bot messages with no letters.** `?` or `BUGTRK-12?` reply in the chat's last language. English commands like `done KEY-12` still work in a Hebrew chat.
4. **Main household edge cases.** Making a non-household main returns 400. Two concurrent "make main" calls never leave two mains (unique partial index plus a transaction). Leaving the main household leaves you with no main until you join or pick another.
5. **Shared text.** The share text may hold several URLs, tracking parameters, an empty title or a URL longer than 2000 characters. The name falls back to the URL slug and then to the store name. A URL longer than 2000 characters loses its query string.

## Task 8: BUGTRK-41: English, Hebrew and Russian in the bots

- **`029_bot_language.sql`:** `bot_chats.language text NOT NULL DEFAULT 'en' CHECK (language IN ('en','he','ru'))`.
- **New `server/src/modules/bots/language.ts`:**
  - `BOT_LANGUAGES`;
  - `detectLanguage(text): BotLanguage | null` (Hebrew block → `he`, Cyrillic → `ru`, Latin letters → `en`, otherwise `null`);
  - `LOCALES = { en: 'en-GB', he: 'he-IL', ru: 'ru-RU' }`.
- **`commands.ts`:**
  - **Patterns:** `PATTERNS: Record<BotLanguage, { keywords, done, use, bought, addToList, assign, when, split }>`.
  - **Parsing:** `parseCommand(raw, language)` tries the detected language, then English. That's how `done KEY-12` works anywhere.
  - **Hebrew:**
    - keywords: `עזרה`, `מטלות?`, `משימות?`, `שלי?`, `פגישות?` / `תורים?`;
    - done: `בוצע|סיימתי|סגור KEY-12[: החלטה]`;
    - use: `עבור ל KEY`;
    - bought: `קניתי|קנינו …`;
    - add to list: `הוסף … לרשימת …`;
    - assign: `… צריך|צריכה|צריכים …`;
    - when: `היום`, `הערב`, `מחר`, `מחרתיים`, `ביום ראשון…שבת`, `ב-D/M`.
  - **Russian:**
    - keywords: `помощь`, `дела?`, `задачи?`, `мои?`, `встречи?`;
    - done: `готово|сделано KEY-12`;
    - bought: `купил|купила|купили …`;
    - add to list: `добавь … в список …`;
    - assign: `… должен|должна|должны|нужно …`;
    - when: `сегодня`, `вечером`, `завтра`, `послезавтра`, `в понедельник…`, `на D/M`.
  - **Splitting items:** split on `,` and `&` in every language, plus ` and ` / ` и `. In Hebrew, split ` ו` only on the last segment, and only when commas are present, so `ורדים` survives.
- **New `server/src/modules/bots/texts.ts`:** `BOT_TEXT: Record<BotLanguage, …>` holds every reply now inline in `handlers.ts:96-387` and every notification line in `notifier.ts:219-345`.
  - Handlers take `t = BOT_TEXT[language]`.
  - `formatDay` / `formatTime` in `format.ts` take the locale.
- **`handleMessage`:** `language = detectLanguage(text) ?? chat.language`. It updates `bot_chats.language` when the value changes (one UPDATE). The notifier and digest use `chat.language`.
- **Tests:**
  - `server/test/telegramCommands.test.ts`: a table of he/ru/en phrases mapped to the expected `Command`, including the `ו` split cases.
